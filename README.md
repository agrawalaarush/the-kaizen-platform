# Kaizen Platform

Continuous Improvement Idea Management System

## Overview

The Kaizen Platform enables employees to submit, review, collaborate on, and track improvement ideas throughout their lifecycle.

## Technology Stack

### Frontend
- React.js
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas

### Authentication
- JWT (JSON Web Tokens)

## User Roles

### Employee
- Submit ideas
- Comment on ideas
- Volunteer for ideas
- Track own submissions

### Reviewer
- Review ideas
- Approve ideas
- Reject ideas
- Update statuses

### Admin
- Manage users
- Manage categories
- View platform statistics
